Implement once, work with everything: Open Game Standards publishes OGS-TS, an open telemetry standard for games and the hardware around them

2026-11-11 · Press kit

Open Game Standards (OGS) today announces version 1 of the OGS Telemetry Standard (OGS-TS), an open, royalty-free standard that lets a game describe what is happening in it once, on the player's local network, so that every motion platform, haptic device, dashboard, light and accessibility device listening can understand it. The standard ships with SDKs for Unity, Unreal Engine and Godot, a .NET reference implementation, a conformance corpus and a desktop monitor, all MIT licensed.

Today almost every connection between a game and the hardware around it is built game by game. The open plugin repository for one motion platform's software alone lists 72 separate game readers. Where games do emit telemetry, it is shaped for one kind of device: a rafting game plugin for another motion platform's software ends up reporting engine RPM and per-corner suspension, because car telemetry is what motion software expects, and a raft has no engine. Developers support each device separately, and device makers chase each game separately.

OGS-TS replaces that with three frame types on one UDP multicast group. Discovery frames, every two seconds, declare the game, its objects and a dictionary of channels, each with a name, type, unit and range. Motion frames carry the bare samples at the game's own rate; a pose-only frame is about 70 bytes. Event frames carry impacts, gunfire and other stimuli, with replay and deduplication so a lossy network cannot drop them. The stream is read-only, so it cannot be used to cheat, and it never leaves the player's network.

For game developers, adding OGS-TS is a small task, not a whole project. Add a publisher to the player's vehicle or character, declare channels and bind values. The SDKs are plain source with no third-party runtime dependencies and build wherever their engine builds, including ARM and ahead-of-time platforms such as IL2CPP.

For hardware developers, one receiver works with every OGS-TS game, because each game declares its own channels. Devices can build a receiver in and need no control software on a PC. Every implementation emits byte-identical frames, checked against a shared conformance corpus, so "done" is testable. The OGS-TS Monitor, a cross-platform desktop receiver, shows every sender on the network and flags anything that does not conform.

The schema has been mapped against more than a hundred documented game outputs across sixteen validation exercises with no open gaps, including all 1,354 Microsoft Flight Simulator 2024 variables. It has already been tested in ten shipped games through loader mods, with no changes to the games: Subnautica Below Zero, Hyper Storm, Exo One, Sable, Turbo Golf Racing, Torque Drift, Hot Wheels Unleashed, The Gunk, Stray and RoboCop: Rogue City. For hardware makers needing content on day one, OGS-TS Bridge, in development, already translates the telemetry that Forza, F1, Assetto Corsa Competizione, Microsoft Flight Simulator and others emit to the OGS-TS format.

Motion is the first use, not the only one. The same stream can drive smart lighting, streaming overlays, second-screen dashboards, smart bike trainers, and accessibility cues that turn footsteps and impacts into directional haptics, including from standalone VR headsets with no PC involved.

"Every game either doesn't provide the data, provides it in a vendor-locked way, or provides it in a shape nobody understands. A standard nobody adopts is worthless, so mine had better be adoptable. That is why the SDKs, the conformance corpus and the loader mods all exist: so that when a game or hardware developer looks, everything they need is already sitting there."

Brian Gilbert, founder of Open Game Standards

About Open Game Standards

Open Game Standards writes open, royalty-free standards for the connections between games and the hardware and software around them, and ships the tools to adopt them. It was founded by Brian Gilbert in 2024 and is developed in the open. The OGS Telemetry Standard is its first published standard.
