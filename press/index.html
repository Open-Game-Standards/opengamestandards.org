Fact sheet

Organisation
Open Game Standards (OGS)
Founded
2024, by Brian Gilbert
What it does
Writes open, royalty-free standards for the connections between games and the hardware and software around them, and ships the tools to adopt them
First standard
OGS Telemetry Standard (OGS-TS), version 1: live game telemetry to motion platforms, haptics, dashboards, lighting, accessibility devices and loggers, over UDP multicast on the local network
Licence
MIT; free for anyone to implement
SDKs
Unity (2022.3+ and Unity 6), Unreal Engine, Godot 4 (.NET), and a .NET reference implementation; no third-party runtime dependencies
Tools
OGS-TS Monitor (cross-platform receiver and conformance checker); OGS-TS Bridge (available to download, in active development, Windows); GameConn (in active development)
Validation
100+ documented game outputs mapped across 16 exercises with no open gaps; tested in 10 shipped games through loader mods
Website
opengamestandards.org
Source
github.com/Open-Game-Standards

Descriptions

One line. Open Game Standards writes open, royalty-free standards that let games and the hardware around them work together without per-game integrations.

Paragraph. Open Game Standards writes open, royalty-free standards for the connections between games and the hardware and software around them, and ships the tools to adopt them. It was founded by Brian Gilbert in 2024 and is developed in the open. The OGS Telemetry Standard is its first published standard.

Naming. Write "Open Game Standards" in full at first mention, then "OGS". The standard is the "OGS Telemetry Standard (OGS-TS)", then "OGS-TS".
